# 게임 모델링 & 학습 환경 구현도

> 스페이스 크루(The Crew: Planet Nine)를 Unity ML-Agents로 모델링한 환경의 **구현 현황 지도**.
> "무엇이 어디에 구현돼 있고, 어디까지 됐고, 뭐가 부족한지"를 한눈에 추적한다.
> 관련: 학습 기록 [`RL_history.md`](RL_history.md) · 천장 측정 [`ceiling.md`](ceiling.md)

## 범례
- ✅ **완료** — 규칙대로 구현·동작
- 🟡 **부분** — 동작하나 간소화/근사/하드코딩 등 한계 있음
- 🔴 **미구현** — 관측만 있거나(obs-only) 아예 없음
- ⚪ **의도적 제외** — 학습 범위 밖(예: 인간 UI 전용)

> 갱신 규칙: 모델링이 바뀌면 이 문서의 해당 행 상태/비고를 같이 고친다. 새 서브시스템은 §4 표에 추가.

---

## 1. 개요

- **게임**: 4인 협동 트릭테이킹. 카드 40장 = 색 4종(Yellow/Blue/Green/Pink) × 1~9(36장) + 로켓(트럼프) 1~4(4장).
- **목표**: 학습된 정책으로 50개 미션을 각각 N회 수행해 성공률 측정.
- **현재 단계**: **베이스(트릭테이킹 + 과제 드래프트)** 협력 학습. 특수 규칙은 코드엔 있으나 **현재 학습엔 미적용**(§5).
- **AI**: 4명 모두 MA-POCA로 동시 학습(중앙집중 critic + 그룹 보상). MCTS·규칙기반은 비교/천장용 베이스라인.

### 에피소드 흐름 (페이즈 = `GamePhase`)

```
Setup(배분)
  → 함장 결정 (로켓4 보유자, TrickManager.FindCaptainIndex)
  → TaskSelection : 드래프트 (함장부터 시계방향 take/pass, T<R)   ← CrewAgent 액션 Branch0/1
  → DistressSignal: AI/배치 스킵 (인간 전용)
  → Playing       : 트릭 ×10
        트릭마다 → OnCardPlayed → 4장 모이면 승자 판정
                 → OnTrickResolved: 타깃 카드 트릭이면 과제 완수/실패, 전역규칙 per-trick 판정
  → OnHandEnded   : 전역규칙 최종 판정 → 미션 성공/실패
  → 보상 지급 → EndGroupEpisode → 재시작
```

## 5. 관측·액션 상세

**관측 313** (`CrewAgent`):
`40 손패 + 40 테이블(드래프트 땐 풀 슬롯) + 5 리드 + 162 팀 태스크(4명×슬롯, 순서토큰 포함) + 4 손패수 + 4 트릭승수 + 2 플래그 + 24 통신(4명×6) + 32 특수규칙`

**특수규칙 32칸**: `[0]데드존 [1]통신차단트릭 [2]통신불가활성 [3]viewer통신금지 [4]사령관결정 [5]사령관분배 [6]토큰이동 [7]카드교환 [8]순서토큰존재 [9~18]전역규칙 one-hot(1~10) [19]전역규칙활성 [20~31]예비`

**액션 `[10,2,4]`**: `Branch0`=카드/풀슬롯, `Branch1`=통신(플레이)·take/pass(드래프트), `Branch2`=예비(마스킹).

> 관측 크기는 고정(313)·특수규칙 32칸에 헤드룸 → 특수규칙을 켜도 크기 불변 → `--resume`/`--initialize-from` 전이 안전.

## 6. 부족·미달 부분 (우선순위)

### 🔴 학습 핵심 (지금 중요)
1. **드래프트 미학습** — 정체(38%)의 병목. → 드래프트 보상(B)으로 대응 중(Run5). [`ceiling.md`](ceiling.md)
2. **measure=reward 비단조** — 커리큘럼 진급 신호 결함(부분점수가 난이도 가림). 별도 대응 예정.

### 🟠 특수 규칙 enforce (Phase 2 전 수정)
3. **m46/m50 enforce 없음** — obs·DB만 있음.
4. **M44 RocketsInOrder** — 로직 정리 필요(`playedCardsInHand` 잔재).
5. **commander_decision/distribution 미구현** — 드래프트 흐름을 바꿔야 함(보류).
6. **순서토큰 이동/교환(M23,40)** — enforce 없음.

### 🟡 통신
7. **NoCommPlayer 하드코딩**(`players[1]`) → 사령관 왼쪽으로.
8. **데드존 AI 라우팅 미흡**(UseCommTokenDeadZone 미연동).

### 🧪 검증 공백
9. **특수 규칙이 학습에서 한 번도 안 켜짐**(env 플래그 0) — 켜는 순간 버그 드러날 수 있음. Phase 2 진입 시 단계적 검증 필요.

> 단계 관점: **현재(베이스 학습)** 에 직접 영향은 #1,#2뿐. #3~#9는 **특수 규칙 커리큘럼(Phase 2)** 진입 전에 정리.

## 7. 이 문서 추적 방법

- 학습 회차별 변화는 [`RL_history.md`](RL_history.md), 성능 천장 근거는 [`ceiling.md`](ceiling.md)에서 교차 확인.
